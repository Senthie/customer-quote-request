# 内部用词对照表 —— 客户英文原文 ↔ 公司内部用词

**用途**：CPMS / 产品名称 / 检测项目里出现的工艺词，按「内部用词」列写；「直译 / 常见误译」列是我方容易照字面译错的地方，见到即改。

**维护规则**
- 新增词条必须带出处（哪张单 / 哪封邮件），没有出处的推断词不进表。
- 内部用词优先取 **ERP 实单已用的写法**，其次取 `docs/华辉内部中英单词表.txt`；两者冲突时以实单为准，并在「出处」列注明冲突。
- 只有出现在 CPMS / 品名 / 检测项目里的词才需要进表；产品题材、客户自造书名不进表。
- 机器可读版同步追加到 `docs/华辉内部中英单词表.txt`（`EN\tZH`，供 `scripts/glossary.py --check` 体检）。

## F. ERP 字段判定映射（不是译名，是取值规则）

| 客户原文 / 情境 | ERP 字段与值 | 易错点 |
|---|---|---|
| `(portrait)` | 书脊方向 = **长书脊** | 单词表 `portrait → 长书脊`。我按尺寸长短填「短书脊」是错的 |
| 正方形（如 140×140）、客户未写方向 | 书脊方向 = 长书脊（业务默认） | 正方形本无长短之分，跟业务默认值 |
| FOB 香港 | 送货地区 = 香港（级联生成） | 纯 HTTP 提交级联下拉不落库，需页面手选 |
| 客户未给装箱要求 | 纸箱类别=普通纸箱 / 纸板类型=A=B双坑纸板 / 底卡=B3B坑纸板 / 装箱方式=平装 / 台板=不打卡板 | 这是**业务默认组合**，不是客户要求；CPMS 里仍写「待确认」 |
| 客户未给目标价 | 客户目标价币种不影响报价 | 填美元（业务默认）而非欧元 |

## G. 命名与固定值

| 项 | 写法 | 出处 |
|---|---|---|
| 产品名称 | `对接人 / 内部品类短称 / 客户书名(FSC类别)`，如 `Cornelia / 眼仔普通BB书 / Kontrast-Wackelaugen-Pappe(FSC Mix)` | BJXQ261118004、BJXQ261117002-01 |
| 内部品类短称 | 眼仔普通BB书、超绝精装书 | 同上。不用「对比图案活动眼BB书」「德文豪华版方脊精装书带书套」这类描述式命名 |
| 产品英文名 | 照抄客户 docx 原文，含 en dash `–`，不换半角 `-` | `Biss zum Morgengrauen (Bella und Edward) – Deluxe Sonderausgabe` |
| 修改记录 | 新款报价 / 更改尺寸和P数 / 原单更新报价 | 三张实单 |
| 表头备注 | 业务实单通常**留空** | 三张实单 Remark 全空；内部待确认事项走 CPMS 或另沟通，不塞表头 |
| 改版单 | 原单做 `-01`，带 原表单编号 / 原明细ID / 返单香港单号 / 原产品描述，CPMS 用 `=====` 分隔块承接补充描述 | BJXQ261118004-01、BJXQ261117002-01 |
