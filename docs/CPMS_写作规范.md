## 0. 一句话

CPMS 不是自由散文，是**有骨架的结构化产品描述**：一行概要 + 若干「部件：材料，尺寸，印色，工艺」+ 装订/包装/装箱 + 备注。
骨架、词表、取值语法全部定死，剩下的空白只有「事实是什么」。

新写法（合格样例，来自真实单据 `BJXQ230403003` 改写）：

```
书籍方向：【长书脊】产品规格：【148*210*0】共【2】款

封面：230g单粉(FSC)，4C+光胶/0C，有机封宽80mm
衬纸：8PP，120g书纸(FSC)，1C/1C，前后衬纸粘胶宽6mm
内文：160PP，100g书纸(FSC)，4C/4C
装订：空脊锁线胶装书（带衬纸）
包装：不收缩+可移语言贴(31-3)
装箱：20本/混箱，本单8本与FJ23040301的12本混装，外箱放2张B3B普通芯坑纸板（长宽各减0.5英寸）

备注：2款封面文件不同、内文文件相同；请选配DPU
```

## 1. 为什么要重设计（18476 份实测）

数据来源：`/home/claw/train/custom_cpms_requie`，2021-08 起近 4 年 ERP 报价需求单导出，**18476 份，键集完全一致（59 键）**，其中 81 份 CPMS 为空。

### 1.1 好消息：多数人已经在用同一套写法

| 事实 | 数据 |
|---|---|
| 以「书籍方向：【X】产品规格：【a*b*c】共【N】款」开头 | **91.2%**（16769/18395） |
| 概要行「书籍方向」与 `Drop_SJFX` 字段一致 | **100%**（16772 份，0 例外） |
| 概要行「共【N】款」与 `TZS` 字段一致 | **100%**（7765 份，0 例外） |
| 概要行尺寸与 `CD/KD/GD` 一致 | **98.1%**（352 份差异全是取整：`228.6`→`228`） |
| 段落主干顺序：封面 → 内文 → (夹层) → 装订 → 包装 → 装箱 | 转移频次最高的链（12453 / 11828 / 6526 / 4972） |

**结论：这不是推倒重来，是把 91% 的人已经在用的写法钉死成规范。** 概要行是**派生数据**（能从结构化字段算出来），所以它天然已经高度一致 —— 这也说明规范该往哪个方向走：可派生的必须派生。

### 1.2 坏消息：剩下的是真乱

| 问题 | 覆盖率 | 说明 |
|---|---|---|
| 出现 **3176 种**不同行首标签 | — | `封面/前封面/后封面/封底`、`内文/内页`、`装订/装订方式/装订顺序`、`箱唛/箱唛贴`… 同义写法未收敛 |
| 混入 `【姓名   日期】产品补充描述` 内部讨论块 | **49.6%** | 一半的单子把「微信聊天记录」写进了产品描述，最新变更与最终规格混在一起 |
| 使用 `=====` 分隔线 | **49.4%** | 用于分隔上述讨论块 |
| 含 CR / CRLF | **99.6%** | 只允许 LF，否则跨系统换行渲染不一致 |
| 四段齐全（封面/内文/装订/装箱） | **53.9%** | 缺段 = 报价依据不全 |
| 出现空标签（只有「封面」没有值） | **28.6%** | 5 份 CPMS 全文就是「产品规格：【200*200*0】\n封面」 |
| 段序错乱 | **25.0%** | 典型：`装订` 写在 `内文` 之前、`客户目标价` 写在 `封面` 之前 |
| 印色写法不统一 | **72.4%** | `4/0c` `4C/0C` `4c+光油/0c` `4+光油/0C` `4C/0C` 五种并存 |
| 克重单位不统一 | **40.9%** | `g`（11831）· `gsm`（3769）· `克`（2538） |
| 尺寸分隔符不统一 | **22.0%** | `x` / `X` / `×` / `*` |
| 行尾带空格 | **25.9%** | 含整行 150 个空格的「排版」 |
| 商务要求（请拆分/请选配/客户目标价）混在产品段里 | — | 应在最后 |

**合规度基线：18476 份里 0 份完全合规，中位数 5 个 error，最多 143 个。**
只做机械规范化（换行/冒号/单位/分隔线）后仍有 86.3% 不合规 —— 说明必须改写法，不是改格式。

### 1.3 长度分布（用来判断写得够不够）

| p5 | p25 | p50 | p75 | p90 | p99 | max |
|---|---|---|---|---|---|---|
| 171 | 339 | **510** | 761 | 1083 | 2149 | 13537 |

中位 510 字 ≈ 概要行 + 6~8 行部件/工序。写成 2000 字以上的（前 1%）基本都混了变更过程。

## 2. 骨架

顺序固定，**可整段省略，不可乱序**（`assets/cpms_spec.yaml: sections[].order`）：

```
[0]   概要行        书籍方向：【长书脊】产品规格：【CD*KD*GD】共【N】款/件，每款【M】语言
[100] 主体部件      皮壳 → 封面 → 后封面 → 前封面 → 皮壳衬纸 → 内兜 → 内兜衬纸 → 衬纸
                    → 内文 → 内文连衬纸 → 封面连内文 → 夹层 → 内文夹层 → 灰板 → 面纸
[200] 附属部件      贴纸 → 单张 → 卡片 → 砌图 → 说明书 → 内托 → 内袋 → 底卡 → 腰纸
                    → 书套 → 封套 → 陈列盒 → 信封 → 吸塑 → 自粘袋 → 发声器 → 磁胶玩具
                    → 配件 → 客供配件 → 布袋
[300] 工序          装订 → 装配 → 包装 → 装箱 → 箱唛
[400] 报价备注      客户目标价 → 请拆分 → 请选配 → 此单半返 → 备注
```

表里 `order` 相同的两个段落 = **同级**，先后都合法（如 `陈列盒` 与 `内托`：内托常在盒里，谁先写都行）。

两条顺序原则，记住这两条就不用背表：

1. **部件自外向内、自前向后**（先皮壳封面，再衬纸，再内文，再夹层；先主体，再附属件）。
2. **工序按生产顺序**（装订 → 装配 → 包装 → 装箱 → 箱唛），**商务要求一律最后**。

### 2.1 概要行 = 派生数据，不许手写

```
书籍方向：【{Drop_SJFX}】产品规格：【{CD}*{KD}*{GD}】共【{TZS}】款
```

| 情况 | 写法 |
|---|---|
| `TZS` ≤ 1（书本）或单件套装 | 省略「共【N】款/件」 |
| 套装实物 ≥2 件 | 必须写「共【N】件」，N = **实物件数** = 组成声明里每项数量之和（`陈列盒+4款卡片+信封+自粘袋` = 7 件） |
| `YYS` > 1 | 追加「，每款【M】语言」 |
| `Drop_SJFX` 为空（套装） | 省略「书籍方向：【…】」，直接从「产品规格：」开始 |
| `GD` = 0 | 保留 `0`（表示厚度未定/不计），**不写「待定」** |

> 尺寸用**原始精确值**（可 1 位小数）：`228.6*254*0`。ERP 的 `CD/KD` 是整数，四舍五入的差是**允许且明确的**（352 份历史数据都这样），不要反过来把概要行改成整数 —— 那是生产要用的真实尺寸。

### 2.2 必填段

| 产品形态 | 必填 |
|---|---|
| 全部 | `装箱` |
| 书本类（CPLB 顶层 22~28 或 ZDFS≠套装） | `装箱` + `封面`（或`皮壳`）+ `内文` + `装订` |
| 套装/盒类 | `装箱` + 至少一个部件段（`1套=…` 的组成声明也算） |

> **唯一允许写「待确认」的位置是必填段**（`装箱：待确认（原单未给装箱要求）`），**这种产物可以交付**（业务 2026-10-19 拍板）。
> 其余段落推不出来就**整行不写** —— 空标签（只有「封面」没有值）是错误，不是省略。

## 3. 行内语法：一行一个部件，槽位固定

```
部件：{数量}，{材料}，{尺寸}，{印色+表面处理}，{结构工艺}
```

五个槽位**可整槽省略，不可跳序**：

| # | 槽位 | 写法 | 例 |
|---|---|---|---|
| 1 | 数量 | 阿拉伯数字 + 量词 | `12张` `40个` `每张` `共10张` |
| 2 | 材料 | 克重/厚度 + 纸名 + `(FSC)` + 裱/对裱 | `300g单粉(FSC)` `1500g灰板(FSC)` `350g粉灰裱W9坑纸板(FSC)` |
| 3 | 尺寸 | `长*宽*厚mm`，单位只写一次 | `228.6*254mm` `150*50*200mm` |
| 4 | 印色 | `{n}C{+工艺}{+工艺}/{m}C` | `4C/4C` `4C+哑胶+局部UV(30%)/0C` `Pantone 806C/0C` `0C/0C` |
| 5 | 结构工艺 | 对裱 / 啤 / 圆角 / 冲形状 / 揭页 / 拉卡 / 穿线 | `对裱，圆角` |

槽位之间用**中文逗号 `，`**；同一面多个表面处理用**半角加号 `+`** 挂在印色后。

### 3.1 单位与数字（硬规矩）

| 要写 | 不写 |
|---|---|
| 克重 `300g单粉` | `300gsm单粉` `300克单粉` `300g 单粉` |
| 灰板 `1500g灰板` | `2.5mm灰板` `2.5MM灰板`（灰板一律写 g，会被判 CPMS054） |
| 厚度（非灰板） `2.5mm` | `2.5MM` `2.5 mm` |
| 尺寸 `228.6*254mm` | `228.6x254mm` `228.6X254MM` `228.6×254mm` |
| 印色 `4C+哑胶/0C` | `4/0c` `4c/0c` `4+哑胶/0C` `4C+哑胶/0c` |
| 不印 `0C/0C` | `不印色` `不印` `-` |
| 专色 `Pantone 806C` / `1C+专色(金属银)/0C` | `806C专色` `金属银色` |
| FSC `300g单粉(FSC)` | `FSC纸` `FSC用纸` `FSC认证纸` `300g单粉FSC` |
| 百分比 `局部UV(30%)` | `局部UV30%` `局部UV 30 percent` |
| 金额 `2.6美元` | `US$2.6` `USD 2.6` `2.6$` |

> 灰板厚度一律写 **g**（业务 2026-10-19 拍板）：`600g=1mm`、`900g=1.5mm`、`1200g=2mm`、`1500g=2.5mm`、`1800g=3mm`。
> 客户原文给 mm 就按这张表换算；表里没有的厚度不许估，回头问业务。

### 3.2 印色槽的三种形态

| 形态 | 写法 | 含义 |
|---|---|---|
| 双面 | `4C/4C` | 正面 4 色 / 背面 4 色 |
| 带表面处理 | `4C+哑胶+局部UV(30%)/0C` | 正面 4 色 + 哑胶 + 30% 局部 UV；背面不印 |
| 专色 | `Pantone 806C/0C` | 正面专色，背面不印 |

**表面处理书写顺序**（同一面多个时按此序，否则算「写法不规范」）：
`光油 → 哑油 → 光胶 → 哑胶 → UV → 哑UV → 局部UV → 烫金 → 击凸 → 压纹`

### 3.3 闭集词表

**纸名**（前面写克重/厚度）：

```
单粉 · 双粉 · 哑粉 · 光粉 · 书纸 · 粉灰 · 灰板 · 单粉卡 · 高松厚单粉 · 牛皮纸 ·
白格纸 · 铜版贴纸 · 格拉辛 · OPP · PET · RPET · B3B（坑纸板：B3B / W9 / A=B / K=B / B=B）
```

同义收敛：`铜板→铜版`、`单粉咭→单粉卡`、`单粉纸→单粉`、`光粉纸→光粉`。

**表面处理**：`光油 · 哑油 · 光胶 · 哑胶 · UV · 哑UV · 局部UV · 烫金 · 击凸 · 压纹 · 过油`

**装订**：`骑马钉 · 锁线胶装 · 无线胶装 · 胶装/PAD书 · 线圈书 · YO圈 · 蛇圈 · 精装 · 普通BB书 · 揭页 · 套装`

**段落标签**：46 个（见 `--vocab`）。

### 3.4 词表外的东西放哪

| 情况 | 写法 |
|---|---|
| 需要说明某页/某张的差异 | `- 第一张内文右边：…`（三级子项，`- ` 开头，豁免词表） |
| 不在词表的部件（如`书架`） | 用最近的规范标签（`单张`），再加 `- ` 子项说明 |
| 一句话补充 | 写进 `备注：` |

## 4. 多款 / 多件

`TZS > 1`，或一套由多个可独立报价的件组成时：

```
书籍方向：【长书脊】产品规格：【153*153*0】共【4】款

1. 普通BB书
  封面连内文：24PP，350g单粉(FSC)对裱，4C+UV/0C，153*153mm
  装订：普通BB书，圆角

2. 精装揭页BB书
  皮壳：157g光粉(FSC)+1500g灰板(FSC)，4C+光胶/0C
  内文：10PP，350g单粉(FSC)对裱，4C+UV/0C，153*153mm
  夹层：12张，350g单粉(FSC)，0C/0C
  装订：精装BOBO书

装配：4本入1个书套盒
装箱：请建议装箱数量，外箱不超过12kg
```

规矩：

- 序号 `1. ` `2. ` `3. `（阿拉伯数字 + 半角句点 + 一个空格），禁 `1、` `①` `(1)` `2.书架：`（序号与部件挤一行）。
- 款内行**缩进 2 个空格**；款与款之间**一个空行**（不多不少）。
- 概要行只在最顶部出现**一次**；款内不重复。
- 套装先写 `1套=A+B+C` 组成声明，再逐件写。

## 5. 六条硬规矩（违规即 error）

| # | 规矩 | 原因 |
|---|---|---|
| 1 | **只写当前生效的状态**，不写变更过程 | 49.6% 的单子把讨论记录写进来，报价员读不出「最终规格」 |
| 2 | **不写 `=====` 分隔线、不写 `【姓名   日期】产品补充描述`** | 同上；变更点折算成 `备注` 一行（`本单基于 KHDDxxxx 返单，变更：…`） |
| 3 | **不写空标签** | `封面` 两个字的 CPMS 有 5289 处，等于没写 |
| 4 | **不用同义标签** | 3176 种标签里绝大多数是同义漂移 |
| 5 | **商务要求（请拆分/请选配/客户目标价）放最后** | 与产品实体无关，混在部件里会被漏读 |
| 6 | **一行只写一个部件** | 一行塞两个部件无法解析，也读不清 |

版式（也全是 error）：只允许 `\n`；不用制表符；行尾无空格；最多一个连续空行；首尾无空白；标签用全角冒号 `：`。

### 6.2 `BJXQ240405003` — 精装揭页BB书 4 款（含烫金明细）

## 7. 工具与门禁

```bash
cd /home/claw/customer-quote-request

uv run ./scripts/cpms_lint.py <ERP.json>            # 校验（退出码 = error 数）
uv run ./scripts/cpms_lint.py <目录> -r             # 批量（跳过 _superseded_）
uv run ./scripts/cpms_lint.py <ERP.json> --fix      # 机械规范化（改前自动 .bak）
uv run ./scripts/cpms_lint.py --text "…"            # 直接校验一段文本
uv run ./scripts/cpms_lint.py --vocab               # 打印骨架与闭集词表
```

`--fix` 做**机械修复**：CR/CRLF→LF、制表符、行尾空格、连续空行、分隔线、半角冒号、同义标签、`gsm/克→g`、`x/X/×→*`，以及**部件行整槽补印色 C**（`4/0c → 4C/0C`）。

补 C 的三条保护（业务 2026-10-19 拍板「可以自动修」，但修法要窄）：

- 只在**部件行**（order 100~299）动手 —— `备注` / `请拆分` / `客户目标价` 段不碰；
- 只在**整槽**上动手（值按 `，` 切槽），`书脊1/2处烫金` 这类比例不会变成 `1C/2C`；
- 灰板 `mm → g` **不自动换**（属材料语义），只报 CPMS054，人按 `600g=1mm` 表换算。

实测：18476 份里旧版 `--fix` 能让 13.7% 直接合规，中位 error 5 → 3；补 C 上线后会再高一些。

规则码（`assets/cpms_spec.yaml` 的 `rules:`）：

| 码 | 级别 | 含义 |
|---|---|---|
| CPMS001~008 | error | 版式（CR / Tab / 行尾空格 / 连续空行 / 首尾空白 / 分隔线 / 内部讨论块 / 半角冒号） |
| CPMS010~012 | error | 概要行缺失 / 与字段不一致 / 重复 |
| CPMS020~023 | error | 标签不在词表 / 同义标签 / 空标签 / 序号与部件同行 |
| CPMS030 | error | 段落顺序错 |
| CPMS040 | error | 缺必填段 |
| CPMS050~054 | warn | 克重单位 / 尺寸分隔符 / 印色写法 / 表面处理顺序 / 灰板单位 |
| CPMS060 | warn | 商务要求出现在装箱之前 |
| CPMS070 | warn | 过长（>4000）或过短（<60） |

## 8. 落地方式

| 环节 | 做法 |
|---|---|
| **agent 写 CPMS** | 按本规范写；写完必须跑 `cpms_lint.py`，error 清零才交付 |
| 交付闸门 | 查看器「未完成」徽章（`CPMS` 为空 / `CPMC_ZH` 占位符）之外，再加一条 `cpms_lint` 退出码 |
| 历史数据 | 不批量回改（ERP 里的老单是已发生的报价记录）。新单一律按新规范；老单只在返单/复用时重写 |
| 客户原话 | 客户的用词（如 `single wall` / `Aufdruck`）先翻译成词表里的词，客户特殊叫法写进 `备注：客户称「…」` |

### 已拍板（2026-10-19，规范 v1 → v2）

| # | 问题 | 决定 | 落地 |
|---|---|---|---|
| 1 | 套装/多件用「款」还是「件」 | **套装多件用「共【N】件」**；书本/多款仍用「款」。N = **实物件数**（业务二次确认） | 概要行接受 `款/件`；套装写「款」、书本写「件」都是 CPMS011；套装件数必须等于组成声明的实物件数（每项开头数量之和，没写数量算 1 件） |
| 2 | 印色补 C 能否自动修 | **能，`--fix` 自动修** | 只对部件行（order 100~299）的**整槽**补 C；备注段与 `1/2` 这类比例不碰 |
| 3 | `备注` 能否保留变更出处 | **可以** | 允许一行「变更点 + 出处/人名」（如 `信封改为1C金属专色（2025-03-25 黄秋芬）`）；仍禁止 `【姓名 日期】` 讨论块 |
| 4 | 灰板写 g 还是 mm | **一律写 g** | 值语法只认 `1500g灰板`；写 mm 报 CPMS054 warn（附 600g=1mm 换算表） |
| 5 | `装箱：待确认` 能否交付 | **可以交付** | 仍是唯一允许「待确认」的位置；其余必填段缺失照样 error |
