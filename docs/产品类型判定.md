# 产品类型（ERP 字段 CPLX）怎么定

> 原始资料：森西 2026-11-20 上传《客户订单/客户报价需求单的产品类别方式》（原文照抄在 §1，
> 未改写）。§2 起是我们落到 ERP 字段与 MCP 工具上的操作口径。
> ERP 字段：`CPLX`（label「产品类型」，select，存 label）。
> 下拉合法值：`新产品` / `返单产品` / `半返单旧产品` / `半返单新产品` / `特殊新产品`
> （见 `assets/erp_form_schema.yaml` §CPLX）。

## 0. 一句话

**第一次做货 → 新产品（有特殊工艺 → 特殊新产品）；做过的货 → 看「这次和上次差什么」：
只差文件/装箱/贴纸 → 半返单旧产品；差刀线/形状/部件/用料/工艺 → 半返单新产品；
一模一样 → 返单产品。NGV 客户没明说「文件跟上次一样」→ 一律半返单旧产品。**

## 1. 原文（森西上传，照抄）

### 返单产品

产品用料，尺寸，文件和之前订单完全一样的情况下为返单产品。数量变更，价格变更，装箱数量变更不影响。装箱方式和价格贴纸增加变更为半返单

#### 半返单产品

此类选项为我们和客人合作开了产品，做的任何处理事项，包含报价，制版、订单，分成以下2种解释--半返单新产品和半返单旧产品。

##### 半返单新产品

之前做过的产品有以下任意一种变动情况则判定为半返单新产品

1. 小部件或者书本的文件内容和书本内的形状或者窗口等更改，
1. 做法或者客人提出工艺优化的更改.
1. 客人缩减成本，修改用料.
1. 一个订单里面部分语言/款是改文件，部分语言/款修改了部件刀线，也选半返单新款、

注：尺寸更改了需要把订单描叙修正，如有修改后的尺寸没有清晰知道的时候，可以描叙注明清楚跟文件尺寸.

##### 半返单旧产品

客人的整个产品用料和所有外围尺寸和内文等其他小部件形状，尺寸，做法都和跟之前订单一样，（仅仅只是修改了文件的内容或者装箱方法变更和贴纸增加变动）的情况下为半返单旧款

### 全返单

规格，材料，文件都跟上次订单一模一样。
一般 NGV 客户如果没有在邮件里面说书本印刷文件跟上次订单一模一样，我们都是录 ‘半返单旧产品’，因为 NGV 客户很少会有全返单，他通常每次订单都会修改一下封面文件，所以文件不会跟以前订单一样

### 新产品

客户的新项目，第一次做货的情况下为新产品。

### 特殊新产品

客户的新项目，第一次做货时，且产品有特殊工艺，产品复杂，特殊纸面处理，新工艺时的情况下为特殊新产品。

### 多款产品组合

以上出现多款产品组合优先选项顺序--1.特殊新产品--2.新产品--3.半返单新款--4.半返单旧款--5.全返单产品

有时候 客户会发送一封`返单`邮件，通常是通过客户的订单号去ERP订单`列表-客户订单`页面查询订单，然后获取改订单的属性，复制生成一份新的订单。如果客户询价的`返单`类型邮件没有给 PO 号，没有说是之前做过货的，我们会去ERP的`列表-客户订单查，一般先按照书本规格查，查不到再按照产品名称查，最后查不到就是判断为：新产品.

## 2. 术语 → ERP 下拉值

| 原文说法 | ERP `CPLX` 落值 |
|---|---|
| 全返单 / 返单产品 | `返单产品` |
| 半返单旧款 / 半返单旧产品 | `半返单旧产品` |
| 半返单新款 / 半返单新产品 | `半返单新产品` |
| 新产品 | `新产品` |
| 特殊新产品 | `特殊新产品` |

**优先级（多款组合时取最高档）**：`特殊新产品` > `新产品` > `半返单新产品` > `半返单旧产品` > `返单产品`。

**默认档（什么都不确定时）**：`新产品`。原因是「查不到历史单」= 客户新项目；只有查到历史单才可能落返单三档。
**NGV 例外**：NGV 系客户（ngv 档案）信件里没写「文件跟上次订单一模一样」→ `半返单旧产品`
（客户极少全返单，每次都会改封面文件）。

## 3. 返单怎么查（ERP「列表-客户订单」）

MCP 工具：`erp_sales_order_list`（`DingDan/DD_KHDD/Index.aspx`，QXID=687，一行 = 一个订单产品行）。
客户订单详情 `erp_sales_order_detail`，子页 `erp_sales_order_node`。

**查找顺序**（原文口径 → 实测可行的做法）：

1. **有 PO 号 / 客户单号** → 直接查 `客户单号`：
   `erp_sales_order_list(key="16258-01", field="客户单号")`。命中就照该单的 `产品类型` 抄
   —— 原文说的「获取该订单的属性，复制生成一份新的订单」就是这个意思。
2. **没有 PO 号** → 先按**规格**查，再按**产品名称**查，都没有 → `新产品`。
3. 规格/名称都查不到但客户明说是返单 → 仍按 NGV 默认档 `半返单旧产品`，并在汇报里点名
   「没查到历史单，按返单默认档落的，请确认」。

### 实测三个坑（2026-11-20，demochen 账号）

- **`field="产品名称"` 的关键字检索不生效**：`key="Taschenlampenbuch" field="产品名称"`
  返回 `total=1` 但 `records` 空。改用 **`field="产品英文名"`** 或 `客户单号` 正常
  （同一条 PO#16258-01 用产品英文名一次就命中 12 行）。
  → 判返单时**优先用 客户单号 / 产品英文名**；中文「产品名称」只用于人眼看。
- **默认日期区间很短**：必须显式给 `from_date` / `to_date`（历史单要往前翻 1–2 年，
  例 `2025-01-01`..`今天`），否则查不到往年的返单。
- **一行 ≠ 一单**：同一 `表单编号` 会多行（多款/多语言），取**最近制单日期**那一行做参照。

### 实例（2026-11-20 建单的 NGV 返单）

询价信：`RE: Reprint enquiry PO#16258-01 Taschenlampenbuch Bobo Siebenschläfer + PAW Patrol`（VEMAG/NGV，目标价 US$1.25/pc）

```
erp_sales_order_list(key="16258-01", field="客户单号", from_date="2025-01-01", to_date="2026-11-20")
→ KHDD25120028  2025-12-18  NGVS16  PO#16258-01/14PP/精装内藏YO书+6PET胶片
   产品英文名 207x243_Mein Taschenlampenbuch WIESE_PR-00085035
   规格 207*243*14   产品类型 = 半返单旧产品
```

→ 这张新询价的 `CPLX` 应为 **半返单旧产品**（不是 `新产品`）。

**已修正（2026-11-20 业务拍板删单重建）**：`BJXQ261120010`（CPLX=新产品）已删除，
重建为 **`BJXQ261120012`**（CPLX=半返单旧产品，数量 20000 / 款数 2 / 语言数 1 / 目标价 1.25 美元，
其余字段与原单一致）。
⚠ **以 2026-11-20 晚的 MCP 版本为准：CPLX 现在可以原地改，不要再删单重建**：

```python
erp_quote_update_product(
    record_id=<记录ID>, cpid=<明细cpid>,
    fields={"product_type": "半返单旧产品"},   # 明细任意字段（与 create 同一套词汇）
    confirm=True)
# 干跑（confirm=false）会回显 changes={"txtCPLX": "…"} + fields={"txtCPLX": "产品类型"}，
# 保存后工具自己逐个回读复核，mismatched 为空即写入成功
```

同一版 MCP 还放开了 **`product_desc`（明细 CPMS/txtCPMS）** 与 **`fields`**（parts_desc /
modify_log / inspection / packing / binding / length-mm 尺寸等）—— 即「描述/规格/装订/产品类型」
全都能原地改，只有主表字段要走 `erp_quote_update`。
（历史记录：今天早些时候本工具还只支持 名称/规格/数量，于是 BJXQ261120010 被删单重建成了
BJXQ261120012；那是当时版本限制下的做法，现在不必如此。）

## 4. 判定速查（给 agent 用）

| 来信特征 | 结论 |
|---|---|
| 客户没做过这个产品 / 查不到历史单 / 提到 new project·新项目 | `新产品`（有特殊工艺 → `特殊新产品`） |
| 第一次做 + 发声/灯光/投影/烫金/UV/击凸/植绒/闪粉/异形模切/特殊纸面处理/新工艺 | `特殊新产品` |
| 做过，只有文件内容/封面文件/装箱方式/贴纸变动 | `半返单旧产品` |
| 做过，刀线/形状/窗口/小部件/用料(克重)/做法/工艺优化有变 | `半返单新产品` |
| 做过，且明确「规格、材料、文件和上次一模一样」 | `返单产品` |
| NGV 系，没明说文件一样 | `半返单旧产品` |
| 多款混合（部分改文件、部分改刀线） | 取最高档：`半返单新产品` |

工具：`uv run ./scripts/product_type.py --text <任务目录或原文> [--customer NGV10] [--lookup]`
—— 输出推荐档位 + 依据 + （`--lookup` 时）ERP 客户订单查询到的历史单证据。
