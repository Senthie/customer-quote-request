## 0. 三句话记住新规范

1. **第 1 行永远是概要行**，而且它是**派生数据** —— 从 `Drop_SJFX / CD / KD / GD / TZS / YYS` 算出来，不许手写漂移。
2. **一行一个部件，槽位固定**：`部件：{数量}，{材料}，{尺寸}，{印色+表面处理}，{结构工艺}`，槽位可整槽省略、不可跳序。
3. **顺序固定、词表封闭**：部件（自外向内）→ 装订 → 装配 → 包装 → 装箱 → 箱唛 → 商务备注；标签只能用 46 个规范标签，纸名/表面处理/装订只能用闭集词表里的词。

## 1. 骨架（顺序固定，可整段省略，不可乱序）

```
[0]   概要行      书籍方向：【长书脊】产品规格：【210*148*12】共【2】款，每款【2】语言
[100] 主体部件    皮壳 → 封面 → 后封面 → 前封面 → 皮壳衬纸 → 内兜 → 内兜衬纸 → 衬纸
                  → 内文 → 内文连衬纸 → 封面连内文 → 夹层 → 内文夹层 → 封面和内文夹层
                  → 发声器夹层 → 灰板 → 面纸
[200] 附属部件    贴纸 → 单张 → 卡片 → 砌图 → 说明书 → 内托 → 内袋 → 底卡 → 腰纸
                  → 书套 → 封套 → 陈列盒 → 信封 → 吸塑 → 自粘袋 → 发声器 → 磁胶玩具
                  → 配件 → 客供配件 → 布袋
[300] 工序        装订 → 装配 → 包装 → 装箱 → 箱唛
[400] 报价备注    客户目标价 → 请拆分 → 请选配 → 此单半返 → 备注
```

**两条顺序原则**（记住这两条就不用背表）：

- **部件自外向内、自前向后**：先皮壳/封面，再衬纸，再内文，再夹层；先主体件，再附属件。
- **工序按生产顺序**：装订 → 装配 → 包装 → 装箱 → 箱唛；**与产品实体无关的商务要求一律最后**。

`order` 相同的两个段落 = **同级**，先后都合法（典型：`陈列盒` 与 `内托` —— 内托常在盒里，谁先写都行）。

### 1.1 概要行怎么写

```
书籍方向：【{Drop_SJFX}】产品规格：【{CD}*{KD}*{GD}】共【{N}】款/件，每款【{YYS}】语言
```

**计数词（业务 2026-10-19 拍板）**：

| 产品形态 | 计数词 | N 从哪来 |
|---|---|---|
| 书本 / 多款（CPLB 顶层 22~28，或 `ZDFS` ≠ 套装） | **款** | `TZS` |
| 套装 / 盒类（CPLB 顶层 29~30，或 `ZDFS` = 套装） | **件** | **实物件数**：`1套=A+B+C` 里每项开头数量之和，没写数量算 1 件（`陈列盒+4款卡片+信封+自粘袋` = 7 件）；没有组成声明就不写 |

| 情况 | 写法 |
|---|---|
| `TZS` ≤ 1（书本）或单件套装 | 省略「共【N】款/件」 |
| 套装实物 ≥2 件 | **必须**写「共【N】件」（N = 实物件数，漏写/写错都是 error） |
| 组成声明怎么写 | 按实物写：`4款卡片` = 每套 4 张；一款多张时写总数（`36张卡片`），不写「4款×9张」—— 件数是逐项求和，不做乘法 |
| `YYS` > 1 | 追加「，每款【M】语言」；`YYS` = 1 或为空则省略 |
| `Drop_SJFX` 为空（套装） | 省略「书籍方向：【…】」，直接从「产品规格：」开始 |
| `GD` = 0 | 保留 `0`（厚度未定/不计），**不写「待定」** |
| 尺寸 | 用原始精确值（可 1 位小数）：`228.6*254`；ERP 的 `CD/KD` 是整数，四舍五入的差是**允许且明确**的 |

### 1.2 必填段

| 产品形态 | 必填 |
|---|---|
| 全部 | `装箱` |
| 书本类（CPLB 顶层 22~28，或 `ZDFS` ≠ 套装） | `装箱` + `封面`（或`皮壳`）+ `内文` + `装订` |
| 套装 / 盒类 | `装箱` + 至少一个部件段（`1套=A+B+C` 组成声明也算） |

> **唯一允许写「待确认」的位置是必填段**（`装箱：待确认（原单未给装箱要求）`）。
> 其余段落推不出来就**整行不写** —— 空标签（只有「封面」两个字）是 error，不是省略。

## 2. 行内语法：槽位固定

```
部件：{数量}，{材料}，{尺寸}，{印色+表面处理}，{结构工艺}
```

| # | 槽位 | 写法 | 例 |
|---|---|---|---|
| 1 | 数量 | 阿拉伯数字 + 量词，或「每张/每本」 | `12张` `40个` `每张` `共10张` |
| 2 | 材料 | 克重/厚度 + 纸名 + `(FSC)` + 裱/对裱 | `300g单粉(FSC)` `1500g灰板(FSC)` `350g粉灰裱W9坑纸板(FSC)` |
| 3 | 尺寸 | `长*宽*厚mm`，单位只写一次 | `228.6*254mm` `150*50*200mm` |
| 4 | 印色 | `{n}C{+工艺}{+工艺}/{m}C` | `4C/4C` `4C+哑胶+局部UV(30%)/0C` `Pantone 806C/0C` `0C/0C` |
| 5 | 结构工艺 | 对裱 / 啤 / 圆角 / 冲形状 / 揭页 / 拉卡 / 穿线 / 磁石 | `对裱，圆角` |

槽位之间用**中文逗号 `，`**；同一面多个表面处理用**半角加号 `+`** 挂在印色后。

### 2.1 单位与写法（硬规矩）

| 要写 | 不写 |
|---|---|
| 克重 `300g单粉` | `300gsm单粉` `300克单粉` `300g 单粉` |
| 灰板 `1500g灰板` | `2.5mm灰板` `2.5MM灰板`（灰板一律写 g，会被判 CPMS054） |
| 厚度（非灰板） `2.5mm` | `2.5MM` `2.5 mm` |
| 尺寸 `228.6*254mm` | `228.6x254mm` `228.6X254MM` `228.6×254mm` |
| 尺寸比较 `250*250mm` | 用 `x` / `X` / `×` 连接数字（会被判 CPMS051） |
| 印色 `4C+哑胶/0C` | `4/0c` `4c/0c` `4+哑胶/0C` `4C+哑胶/0c` |
| 不印 `0C/0C` | `不印色` `不印` `-` |
| 专色 `Pantone 806C` / `1C+专色/0C` | `806C专色` |
| FSC `300g单粉(FSC)` | `FSC纸` `FSC用纸` `FSC认证纸` `300g单粉FSC` |
| 百分比 `局部UV(30%)` | `局部UV30%` |
| 金额 `2.6美元` | `US$2.6` `USD 2.6` `2.6$` |

> 灰板厚度写 **g**（业务 2026-10-19 拍板）：`600g=1mm`、`900g=1.5mm`、`1200g=2mm`、`1500g=2.5mm`、`1800g=3mm`。
> 客户原文给 mm 时按这张表换算（`2.5mm` → `1500g`）；表里没有的厚度不许估，回头问业务。

### 2.2 印色槽的三种形态

| 形态 | 写法 | 含义 |
|---|---|---|
| 双面 | `4C/4C` | 正面 4 色 / 背面 4 色 |
| 带表面处理 | `4C+哑胶+局部UV(30%)/0C` | 正面 4 色 + 哑胶 + 30% 局部 UV；背面不印 |
| 专色 | `Pantone 806C/0C` | 正面专色，背面不印 |

**表面处理书写顺序**（同一面多个时按此序，否则 CPMS053 warn）：
`光油 → 哑油 → 光胶 → 哑胶 → UV → 哑UV → 局部UV → 烫金 → 击凸 → 压纹`

## 3. 闭集词表（不许自创同义词）

**纸名**（前面写克重/厚度）：

```
单粉 · 双粉 · 哑粉 · 光粉 · 书纸 · 粉灰 · 灰板 · 单粉卡 · 高松厚单粉 · 牛皮纸 ·
白格纸 · 铜版贴纸 · 格拉辛 · OPP · PET · RPET · B3B（坑纸板：B3B / W9 / A=B / K=B / B=B）
```

同义收敛（`--fix` 会自动改）：`铜板→铜版`、`单粉咭→单粉卡`、`单粉纸→单粉`、`光粉纸→光粉`。

**表面处理**：`光油 · 哑油 · 光胶 · 哑胶 · UV · 哑UV · 局部UV · 烫金 · 击凸 · 压纹 · 过油`

**装订**：`骑马钉 · 锁线胶装 · 无线胶装 · 胶装/PAD书 · 线圈书 · YO圈 · 蛇圈 · 精装 · 普通BB书 · 揭页 · 套装`

**段落标签**：46 个，用 `uv run ./scripts/cpms_lint.py --vocab` 一次看全。

### 3.1 词表外的东西放哪

| 情况 | 写法 |
|---|---|
| 需要说明某页/某张的差异 | `- 第一张内文右边：…`（三级子项，`- ` 开头，豁免词表） |
| 不在词表的部件（如「书架」） | 用最近的规范标签（`单张`），再加 `- ` 子项说明 |
| 一句话补充 | 写进 `备注：`（例如客户特殊叫法：`客户称「…」`） |

## 4. 六条硬规矩（违规即 error）

| # | 规矩 | 为什么 |
|---|---|---|
| 1 | **只写当前生效的状态**，不写变更过程 | 49.6% 的旧单混了内部讨论，报价员读不出「最终规格」 |
| 2 | **不写 `=====` 分隔线、不写 `【姓名   日期】产品补充描述`** | 同上；变更点折算成 `备注` 一行 |
| 3 | **不写空标签** | 只有「封面」没有值的写法，历史上有 5289 处 |
| 4 | **不用同义标签** | `内页→内文`、`装订方式→装订`、`箱唛贴→箱唛`，共 3176 种历史写法 |
| 5 | **商务要求（请拆分/请选配/客户目标价）放最后** | 与产品实体无关，混在部件里会被漏读 |
| 6 | **一行只写一个部件** | 一行塞两个部件无法解析，也读不清 |

版式（也全是 error）：只允许 `\n`（禁 CR/CRLF）；禁制表符；行尾无空格；最多一个连续空行；首尾无空白；标签用**全角冒号 `：`**。

### 4.1 规则码

| 码 | 级别 | 含义 |
|---|---|---|
| CPMS001~008 | error / warn(008) | 版式：CR·Tab·行尾空格·连续空行·首尾空白·分隔线·内部讨论块·半角冒号 |
| CPMS010~012 | error | 概要行缺失 / 与字段不一致 / 重复 |
| CPMS020~023 | error / warn(023) | 标签不在词表 / 同义标签 / 空标签 / 序号与部件同行 |
| CPMS030 | error | 段落顺序错 |
| CPMS040 | error | 缺必填段 |
| CPMS050~054 | warn | 克重单位 / 尺寸分隔符 / 印色写法 / 表面处理顺序 / 灰板单位 |
| CPMS060 | warn | 商务要求出现在装箱之前 |
| CPMS070 | warn | 过短（<60 字）或过长（>4000 字） |

## 5. 样例集（6 份，均 0 error / 0 warn）

> 每份样例都给了对应的 ERP 字段。概要行必须与这些字段一致 —— 这是 `cpms_lint` 的 CPMS011 检查项。

### 样例 1 · 平装锁线胶装书（最常见形态）

**ERP 字段**：`Drop_SJFX=长书脊` `CD=210` `KD=148` `GD=12` `TZS=1` `YYS=1` `CPLB=23.01;无线胶装书`

```
书籍方向：【长书脊】产品规格：【210*148*12】

封面：250g单粉(FSC)，4C+哑胶+局部UV(30%)/0C
内文：160PP，80g书纸(FSC)，1C/1C
装订：锁线胶装
包装：每本收缩膜，附1张书签
装箱：40本/箱，外箱A=B坑纸板，限重15kg
备注：局部UV范围为书名与主角图形
```

**看点**：单款不写「共【N】款」；`PP` 表示页数；表面处理按 `哑胶 → 局部UV` 的顺序；商务备注最后一行。

### 样例 2 · 精装书（皮壳 + 皮壳衬纸）

**ERP 字段**：`Drop_SJFX=长书脊` `CD=228.6` `KD=254` `GD=15` `TZS=1` `YYS=2` `CPLB=22.01;方脊精装书`

```
书籍方向：【长书脊】产品规格：【228.6*254*15】，每款【2】语言

皮壳：157g光粉(FSC)+1500g灰板(FSC)，4C+哑胶+烫金/0C
皮壳衬纸：140g书纸(FSC)，4C/0C
内文：240PP，100g书纸(FSC)，4C/4C
装订：精装，堵头布+丝带
装箱：24本/箱，每本入1个OPP袋，外箱B3B坑纸板
备注：烫金为书名，击凸为作者名；中英双语两册同箱
```

**看点**：`YYS=2` 必须在概要行追加「，每款【2】语言」；写了 `皮壳` 就不必再写「封面」，只有前后要分别说明时才拆成 `后封面 → 前封面`（顺序按 spec 的 `order`，不是按直觉）。

### 样例 3 · 两款 BB 书（TZS=2，多款结构）

```
书籍方向：【长书脊】产品规格：【153*153*0】共【2】款
```

**看点**：款序号 `1. ` 单独一行、款内缩进 2 个空格、款间一个空行；概要行只在最顶部出现一次；公共工序（装箱）写在所有款之后。

### 样例 5 · 套装（陈列盒 + 卡片 + 信封 + 自粘袋，无书脊方向）

**ERP 字段**：`Drop_SJFX=""` `CD=0` `KD=0` `GD=0` `TZS=1` `YYS=1` `CPLB=29.04;其它套装`

```
产品规格：【0*0*0】共【7】件

1套=陈列盒+4款卡片+信封+自粘袋

1. 陈列盒
  陈列盒：170*140*118mm，350g单粉(FSC)，4C+哑油/0C
  内托：270*225mm，350g单粉(FSC)，4C+哑油/0C，啤后放入盒内

2. 卡片
  卡片：4款，展开321*145mm，成品215*145mm，300g单粉(FSC)，4C+哑油+局部烫金(50%)/0C，对裱，啤后留钉位

3. 信封
  信封：161*115mm，100g书纸(FSC)，1C+专色/0C，开口带背胶

4. 自粘袋
  自粘袋：1个，0.05mm OPP，220*165mm，2个气孔

装配：1张卡片+1个信封入1个自粘袋，1个陈列盒装36个
装箱：24套/箱，外箱A=B坑纸板，限重12.5kg
备注：卡片4款图案各不相同
```

**看点**：套装没有书脊方向 → 概要行从「产品规格：」开始；套装写「共【7】件」= **实物件数**（陈列盒 1 + 卡片 4 + 信封 1 + 自粘袋 1）；先写 `1套=A+B+C` 组成声明再逐件写；套装的录系统尺寸按业务口径为 `0*0*0`，盒内单件尺寸写在件里。

### 样例 6 · 精装音乐 BB 书（含发声器等附属部件）

**ERP 字段**：`Drop_SJFX=长书脊` `CD=250` `KD=250` `GD=20` `TZS=1` `YYS=1` `CPLB=27.17;精装音乐BB书(发声)`

```
书籍方向：【长书脊】产品规格：【250*250*20】

皮壳：157g光粉(FSC)+1500g灰板(FSC)，4C+哑胶+烫金/0C
```

**看点**：`发声器` 属附属部件（order 220），必须写在内文之后、装订之前；电池型号里的 `×` 要写成文字（`LR44 3粒`），否则被判尺寸分隔符（CPMS051）。

## 6. 自检与门禁（写完必跑）

```bash
cd /home/claw/customer-quote-request

# 单份产物（退出码 = error 数，必须 0）
uv run ./scripts/cpms_lint.py <产物 ERP.json>

# 只看一段文本（不核对概要行与字段）
uv run ./scripts/cpms_lint.py --text "书籍方向：【长书脊】…"

# 机械规范化（CR/单位/冒号/同义词），改前自动备份 .bak
uv run ./scripts/cpms_lint.py <产物 ERP.json> --fix

# 打印骨架与闭集词表
uv run ./scripts/cpms_lint.py --vocab
```

`--fix` 只做**机械修复**：CR/CRLF→LF、制表符、行尾空格、连续空行、分隔线、半角冒号、同义标签、`gsm/克→g`、`x/X/×→*`，以及**部件行整槽补印色 C**（`4/0c → 4C/0C`、`4c+光油/0c → 4C+光油/0C`）。

补 C 有三条保护，别当成全文替换：

- **只在部件行**（order 100~299）动手，`备注` / `请拆分` 这些报价备注段不碰；
- **只在整槽上**动手（值按 `，` 切成槽），所以 `书脊1/2处烫金` 这类比例不会被改成 `1C/2C`；
- 灰板 `mm → g` **不自动换**（要有表可查、且属材料语义），只报 CPMS054 提醒，人按 `600g=1mm` 表换算。

交付前还有两道闸门：

1. `CPMS` 非空、`CPMC_ZH` 不含 `【中文品名待定】` —— `uv run python -m erp_view --no-open` 看「未完成」红徽章。
2. `cpms_lint` 退出码 0。

## 7. 写 CPMS 的动作顺序（agent 用）

1. 读任务目录里的 `<原文件>.extracted.json`（规范键 → 值）和原文件本身。
2. 从 ERP JSON 抄出概要行所需的 6 个字段（`Drop_SJFX/CD/KD/GD/TZS/YYS`），**先写概要行**。
3. 判断产品形态（书本 / 套装 / 多款）→ 定计数词（书本「款」= TZS，套装多件「件」= 组成声明的实物件数），按骨架逐行写，**推不出来的段落整行不写**。
4. 客户原话先翻译成词表里的词；客户特殊叫法进 `备注：客户称「…」`。
5. 写完跑 `cpms_lint`，error 清零；有 warn 逐条判断是改写法还是可接受。
6. 变更过程、内部讨论、聊天记录**一律不进 CPMS**，只留最终状态。
